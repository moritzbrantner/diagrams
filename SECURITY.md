# Security Policy

## Supported versions

The latest published minor version receives security fixes. The project is
pre-`1.0`, so older experimental releases may not receive patches unless a fix
can be shipped safely.

## Reporting a vulnerability

Please report security issues privately through GitHub Security Advisories for
this repository. If advisories are unavailable, contact the maintainer through
the repository owner profile and avoid opening a public issue with exploit
details.

Expect an initial response within 7 days. Confirmed vulnerabilities will be
triaged by severity, fixed on a private branch when appropriate, and disclosed
after a patched release is available.
